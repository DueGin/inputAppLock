# InputLock — 第二轮概念（输入法 + 锁定）

## 各方向

### A 中锁 ★推荐
**含义**：锁梁扣在"中"字上，"中"的"口"就是锁体。一个字形同时读作"中"和"锁"。
- 优点：
  - 一个形状讲一件事，一眼读出"中文输入 + 锁住"。
  - 剪影最简单，18 px 菜单栏和 16 px 都清楚。在小尺寸测试中排第一。
  - 菜单栏三态能讲成一个故事：平时是"中"上锁；进入密码框时字换成"A"（英文），锁梁仍在；未启用时锁梁打开。
  - 生图参考也验证了它作为 App 图标的效果。
- 风险：
  - 只出现"中"，对日文、韩文等其他输入法用户的通用性稍弱。
  - 竖笔穿过锁梁，个别人第一眼可能读成"申"或"甲"。如果选它，下一轮会测试竖笔不穿出锁梁的版本。

### B 中/A 锁键（直接使用中/A）
**含义**：挂锁的锁体是一颗印着"中 A"的键帽，直接表达"中英输入被锁定"。
- 优点：中/A 双语最直白，App 图标信息量足，"键帽 + 锁"质感好。
- 缺点：两个字挤在锁体里，16 px 会糊成一团；菜单栏必须简化为只留"中"（见简化稿，效果清楚）。锁体本身仍是常见挂锁造型，可识别度主要靠里面的字。

### C 钉住的中
**含义**："中"的竖笔是一枚图钉，把输入法钉住不动。
- 优点：概念俏皮，"固定"的意思准确，和常见的挂锁图标区分最大。
- 缺点："口"被图钉劈开后像两个括号，"中"的可读性下降；图钉在 16 px 下只剩一根竖线；它表达的是"固定"，没有"锁"那么直接。

### D 中|A 锁定开关（直接使用中/A）
**含义**：一个"中 | A"分段开关停在"中"一侧，滑块戴上锁梁，表示开关拨不动。
- 优点：对"切换被锁住"这个功能的隐喻最贴切，中/A 都在。
- 缺点：构图横向，放进方形图标和菜单栏会偏小，16 px 最弱；菜单栏简化后字母塞不下。另外，早期把"A"包在圆圈里的版本会被读成Ⓐ（无政府符号），已改为 D 形槽。

### E 键盘锁
**含义**：键盘就是锁体，锁梁扣在键盘上。
- 优点：形体最稳，16/18 px 很清楚，键盘一眼可见。
- 缺点：没有中文或中/A 元素，"输入法"只能体现为"键盘"，没有完全解决第一轮"看不出输入法"的问题。

## 推荐
首选 **A 中锁**：最简洁，小尺寸最强，一个形状同时是"中"和"锁"，菜单栏三态（中 → A → 开锁）可以自然派生。

如果坚持要中/A 双字同框，选 **B 中/A 锁键**：App 图标用完整的"中 A"，菜单栏用只留"中"的简化版。

还有一种可能的混合方案：App 图标用 B，菜单栏用 A 的三态。
